# 💱 Konvertues Monedhash

Një aplikacion i thjeshtë dhe i shpejtë për konvertimin e monedhave nga një valutë në tjetrën, duke përdorur kurset më të fundit të këmbimit në kohë reale ose të vendosura manualisht nga përdoruesi.

## 🚀 Funksionalitetet

- 🌍 Konvertim i menjëhershëm midis monedhave të ndryshme
- 💶 Mbështetje për disa nga monedhat më të përdorura botërore:
  - Euro (EUR)  
  - Dollar Amerikan (USD)  
  - Paund Britanik (GBP)  
  - Frangë Zvicerane (CHF)  
  - Jen Japonez (JPY)
- 🔄 Marrja e kurseve të këmbimit në kohë reale nga API (opsionale)
- 🧮 Llogaritje automatike e shumës në Lekë (ose valutë tjetër)
- 💬 Ndërfaqe e thjeshtë dhe intuitive në gjuhën shqipe

## 🛠️ Teknologjitë e përdorura

- **Frontend:** HTML, CSS  
- **Backend:** PHP  
- **(Opsionale)** API për kursin e këmbimit: [ExchangeRate.host](https://exchangerate.host), [Open Exchange Rates](https://openexchangerates.org), ose të tjera.
